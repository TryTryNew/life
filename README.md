# Life · 成為她

只給自己看的生活記錄：喜樂・接受自己・一步一步往前。

- **記錄**：像發脆一樣隨手寫幾句、加照片、選一個標籤（🌼 喜樂／🤍 接受自己／🌱 往前／🔁 失敗了，但回來了）
- **照片編輯**：像 IG 限動一樣在照片上加字、日期、標籤貼紙，也可以保留原圖
- **照片牆**：所有照片的九宮格
- **她**：我想成為的人、這一週的記錄、「她會怎麼做？」情境表
- 資料存在 Firebase Firestore（`logs`、`photos`、`scenarios`、`settings`），手機電腦同步
- 開啟加速：只先載入最近 40 則、列表用小圖（高畫質點開才下載）、service worker 快取網頁本身
- 用 Google 登入，搭配 `firestore.rules` 只讓本人讀寫
- iPhone 捷徑仍可透過 `netlify/functions/addLog.js` 新增記錄

舊版畫面保存在 git 標籤 `v1-old`。
